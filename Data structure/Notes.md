## Graph

### 4 types of graph

#### Directed vs undirected graph
- Directed: there are no arrows between vertex/nodes and edges. Data can go back and forth between nodes.
- Undirected: there are arrows between vertex and edges, so data can only go in one direction.

#### Weighted vs unweighted graph
- Weighted: the edges between the vertexes are different. Some are shorter, some are longer, and these corresponds to different weight of each edge.
- Unweighted: the edges between the vertexes are the same no matter which direction it goes


## Queue

### It is a kind of tunnel that data can only go one-way in to out.

#### Dequeue()
- It says that one element that is at the head goes out of the queue. That means the first element in this queue is deleted.

#### Enqueue()
- It says that one element is added at the rear part of the queue.

#### front()
- It checks the first element at the queue without deleting it.

### isfull()/isempty()
- It checks whether is queue is full or empty. If it is, it returns 1 or true, otherwise, it returns 0 or false.
